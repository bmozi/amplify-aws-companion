# Six sustainability questions, one customer promise

AWS's [Sustainability pillar](https://docs.aws.amazon.com/wellarchitected/latest/framework/a-sustainability.html) can feel like six different worlds. Use one repair-shop story to keep the pieces connected. Maya must durably accept a repair, finish it by the agreed deadline and never promise the same last seat to two people. Each question changes **one design lever**; none cancels those business outcomes. These packets are authored workload teaching reviews, not a completed AWS Well-Architected Tool assessment or measured environmental impact.

For the larger picture, the [A01 six-pillar sample](A01-SIX-PILLAR-SAMPLE.md) follows one repair-request workload through one current official best practice in each pillar. It links actual source evidence to the observation still needed, then sends readers to the [illustrated Unit 32 lesson](../../reader/BOOK-LOCATORS.md#book-c0fb4ecf2653015f) and an untried branch-library transfer. Sampling six practices is not a full workload or lens review.

Keep the customer promise, full-path cost, source revision, permissions, failure path and cleanup visible.

Six linked packets provide **breadth of teaching questions**, not six implemented best practices. Check your own plan, credits, prices, spending and reserve limits, and full-run cost before any live experiment. Organization-dependent work remains design-only in this lab. Actual same-workload AWS measurements, an approved data/retention policy, environmental method, independent learner responses and exact-final book review remain open. The [A01 six-pillar sample](A01-SIX-PILLAR-SAMPLE.md) models how to name missing evidence for one workload.
