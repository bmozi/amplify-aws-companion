# SAP-C02 task 4.2 migration-mechanism review

Internal editorial review, October 19, 2026, against the transitional [official task 4.2 guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-professional-02/solutions-architect-professional-02-domain4.html#solutions-architect-professional-02-domain4-task2). Six knowledge and five skill points have **partial** teaching and fictional changed-case assessment. This does not establish selected-service support, live migration, certification readiness or future SAP-C03 coverage.

| Point | Authored evidence | Still needed |
| --- | --- | --- |
| Knowledge 1: data migration tools | Unit 12 contrasts DataSync, Transfer Family, S3 Transfer Acceleration, Snow availability and a five-day transfer limit; packet asks for source/target fit. | Current pairing, eligibility, sustained throughput, cost and destination behavior. |
| Knowledge 2: application tools | Unit separates AWS Transform MGN rehosting from application acceptance and notes Application Discovery Service closure to new customers; no-agent card changes the route. | Selected OS, agent/connector, license and launched-app evidence. |
| Knowledge 3: networking and DNS | Unit and packet require both directions, VPN/Direct Connect encryption, capacity, name resolution and authority after traffic shift. | Effective routes, addresses, DNS/client cache and measured failure behavior. |
| Knowledge 4: identity | Unit compares continuing directory-aware authentication with a planned Identity Center source change; change card exposes assignment loss. | Selected federation/directory design, sign-in/denial and operator recovery. |
| Knowledge 5: database tools | Unit distinguishes DMS Schema Conversion, data load/CDC and engine-native methods; change card adds cross-engine semantics. | Exact endpoint/version/object support, reconciliation and live rollback. |
| Knowledge 6: governance tools | Unit separates single-account roles/budgets from fictional Organizations/Control Tower design; packet asks for owners and continuing cost. | Real organization estate, prerequisites, controls and funding. |
| Skill 1: database transfer selection | Same-engine backup/restore and supported DMS full load/CDC are conditional choices, not a universal winner. | Representative data and timed source/target tests. |
| Skill 2: application transfer selection | MGN candidate depends on source support and rehost intent; no-agent condition withdraws the proposal as written. | Selected target and customer acceptance. |
| Skill 3: data transfer and strategy | Local `Fraction` arithmetic proves the fictional 8 TiB/80 Mbit/s/five-day path impossible even ideally; change card still treats faster bound as unproven. | Sustained throughput, final changes, verification and current priced design. |
| Skill 4: migration security | Packet asks for least-privilege roles, secrets, keys, encrypted paths, sensitive logs, retained copies and negative checks. | Effective selected policies and observed allow/deny, key and transport tests. |
| Skill 5: governance choice | Packet changes one personal account to a fictional funded multi-account estate without enabling either service here. | Estate-specific owner approval, costs and control evidence. |
