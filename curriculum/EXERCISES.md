# Architecture and operations exercises

These are original teaching exercises, not recalled certification questions. The constraints are fictional. Design responses can be completed locally; AWS execution requires the relevant lab's identity, spending and cleanup prerequisites. Each answer must identify assumptions, compare an alternative and explain what evidence would disprove it. A correct design response does not complete the implementation skills assigned to it in the ledger.

Use this rubric for each exercise: 0 means missing or unsafe; 1 means plausible but unsupported; 2 means correct with stated assumptions; 3 means demonstrated with reproducible evidence and limitations. Score requirements, correctness, security, cost, recovery and explanation separately. Do not average away a zero for forbidden access or data loss. These are editorial learning criteria, not AWS exam scoring.
