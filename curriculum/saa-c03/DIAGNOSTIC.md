# SAA-C03 first-attempt diagnostic

These 28 original questions are a study diagnostic, not official AWS questions, a full-length mock exam or a validated predictor of passing. All organizations, measurements and workloads are fictional. Each of the 14 tasks has two questions; this is not the exam domain weighting. Record one answer unless the question explicitly asks for TWO. No partial credit is used in this diagnostic's raw score.

This diagnostic is optional before reading. You can start with Chapter 1 and attempt it later. Record the chapters you have already studied: a first post-study attempt is not a pre-study baseline. During either attempt, save your own answers without consulting the book, AI or assessor. Record uncertainty rather than researching the answer mid-attempt. Use an unhurried first attempt and record elapsed time; speed can be assessed later using current official practice material. Do not open the separate `assessor/` directory until your first answers are saved. Existing familiarity with a case or key must be disclosed.

For each item record `ID | choices | reason | confidence | time | prior exposure`. A correct guess and a supported answer are different observations. Return your first answers to the facilitator for feedback, then study the linked task route in the main SAA guide.
