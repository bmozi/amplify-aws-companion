# Professional architecture domain 4: study map

Use the [AWS domain 4 guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-professional-03/solutions-architect-professional-03-domain4.html) with these lesson and exercise links. **Partial** means the material practices part of a skill; the last column identifies evidence or practice still needed. It does not establish mastery or exam readiness. Check the current guide for your scheduled exam and verify AWS-specific claims before a real implementation.

## Task 4.2 — disaster recovery architecture

| Skill | Lessons and practice | Scope and further evidence |
| --- | --- | --- |
| 4.2.1 Recovery by RTO, RPO and cost | [Recovery lesson](../reader/BOOK-LOCATORS.md#book-20703bba15f79b2d); [critical-path lab](../examples/recovery-critical-path/README.md); [continuity cases](../examples/business-continuity-path/README.md); [one-promise bridge](../examples/sap-c03-bridge/README.md) | **Partial.** The local graph tests whether planned parallel branches fit a target and rejects missing, wrong-value or conflicting confirmed bookings. Its checks default to unconfirmed and a supplied incomplete inventory blocks a match, but a boolean cannot establish that the inventory is truly complete. The bridge's [exact-case cost checker](../examples/sap-c03-bridge/standby_cost.py) tests a fictional full-run quote, changed meter and shared reserve; the separate local commitment lab tests cooperating processes. No selected live RTO/RPO, independent inventory reconciliation, full-life cost measurement, AWS credit observation or learner result. |
| 4.2.2 Continuous replication with DRS | [Recovery lesson](../reader/BOOK-LOCATORS.md#book-20703bba15f79b2d); [regional cases](../examples/regional-recovery/README.md) | **Partial.** DRS is compared with rebuild and standby; no configured replication or recovery launch result. |
| 4.2.3 Assessment and runbooks | [Reliability lesson](../reader/BOOK-LOCATORS.md#book-56c900b7f81568d4); [controller review](../examples/recovery-controller/README.md) | **Partial.** Resilience Hub, decision, execution and customer proof are separated; no published application assessment or runbook execution. |
| 4.2.4 Multi-Region failover | [Recovery lesson](../reader/BOOK-LOCATORS.md#book-20703bba15f79b2d); [global web cases](../examples/global-web/README.md); [two-writer bridge](../examples/sap-c03-bridge/README.md) | **Partial.** Route, stale client, data authority and return are practiced; no implemented replication or Route 53/Global Accelerator/ARC switch with observed customer recovery. |
| 4.2.5 DR testing and validation | [Reliability lesson](../reader/BOOK-LOCATORS.md#book-56c900b7f81568d4); [resilience exercise](../examples/resilience-exercise/README.md) | **Partial.** Hypothesis, stop condition and customer observer exist; no AWS assessment and bounded fault drill proving recovery. |
| 4.2.6 Multi-cluster container recovery | [Container lesson](../reader/BOOK-LOCATORS.md#book-8444a5a7a3bbe0d5); [illustrated two-cluster lab](../examples/multi-cluster-recovery/README.md) | **Partial.** The local gate makes image, capacity, data, access, health and old-writer checks explicit; no EKS/ECS deployment, timed failover or selected data replication. |

| 4.3.2 Controlled failover measurement | [Reliability lesson](../reader/BOOK-LOCATORS.md#book-3f39f09057e519fc); [local failover clock](../examples/regional-recovery/TIMELINE-LAB.md); [customer recovery lab](../examples/regional-recovery/README.md) | **Partial.** A loopback run timestamps first failed request, incomplete healthy standby, reconciliation, route switch and first correct booking read; a still-open old writer holds without a duration.
