# Developer Associate: a starting route, not a complete exam map

Suppose Maya adds a note feature. A developer must write code that saves the right data, prevents another customer reading it, reaches the intended environment, and remains observable after a release. Those questions overlap with architecture, but the [AWS Certified Developer – Associate guide](https://docs.aws.amazon.com/aws-certification/latest/developer-associate-03/developer-associate-03.html) describes a distinct exam: **DVA-C03**. Its four domains and this book's selected starting points are below. This is an editorial route into existing lessons, not a complete skill inventory, a guarantee of exam readiness, or an official AWS practice test.

For an entry point and a named gap for each of the twelve exam tasks, use the [task route](DVA-C03-TASK-ROUTE.md). The [skill inventory](DVA-C03-SKILL-INVENTORY.md) tracks the separate, still-incomplete individual comparisons.

The guide includes AI-assisted development in Skill 1.1.9 and names AWS AI tools in some testing and troubleshooting skills. Codex can help practice the general habits of proposing a test, explaining code and challenging an assumption; it is not evidence that the reader has used the AWS-specific tools named in the guide. Keep the first answer, assistance and verified result separate. Do not send secrets, state files or customer records to a model as practice data.

## Check the exam version before planning

AWS's October 27 announcement says registration for DVA-C03 is open; its September announcement says DVA-C03 delivery begins December 1, 2026. As checked October 29, some AWS pages describe the registration or last-test dates differently. Treat those dates as a reason to verify your own scheduled exam code and availability directly with AWS, not as a promise in this book. [AWS update announcement](https://aws.amazon.com/blogs/training-and-certification/register-now-updated-developer-associate-and-solutions-architect-professional-exams/); [earlier transition announcement](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/).

This route samples one or two exercises per domain. A complete gap analysis still needs the remaining individual skills compared against current official guidance, compatible hands-on application work, current service behavior, and independent learner review. Before any optional cloud lab, choose the account, scoped identity, Region, whole-run estimate, spending and reserve limits, stop conditions and cleanup owner. Organization-dependent work remains design-only in this companion.
