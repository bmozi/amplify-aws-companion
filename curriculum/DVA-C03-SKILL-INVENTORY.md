# Developer Associate skill inventory

AWS's DVA-C03 guide lists 72 numbered skills in twelve tasks across [development](https://docs.aws.amazon.com/aws-certification/latest/developer-associate-03/developer-associate-03-domain1.html), [security](https://docs.aws.amazon.com/aws-certification/latest/developer-associate-03/developer-associate-03-domain2.html), [testing and deployment](https://docs.aws.amazon.com/aws-certification/latest/developer-associate-03/developer-associate-03-domain3.html), and [troubleshooting](https://docs.aws.amazon.com/aws-certification/latest/developer-associate-03/developer-associate-03-domain4.html). This count was checked against those pages on October 29, 2026. Consult the current AWS guide for the actual skill wording and exam scope; the inventory records identifiers and does not reproduce the guide.

The [CSV inventory](DVA-C03-SKILL-INVENTORY.csv) starts an individual comparison. **All 72 skills now have partial starting points; none is marked fully covered.** “Not assessed” means no skill-level comparison has been recorded here; it does not mean the book necessarily lacks relevant material. “Partial” describes only the named example and its stated limits. Neither label establishes mastery, full task coverage, a live AWS result, or readiness to sit the exam.
