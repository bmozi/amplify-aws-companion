Recover the service

Maya needs recent repairs back and customers able to use the service again. A recent backup and a quick recovery answer different questions.

Reduce the snapshot interval without changing recovery time. Which promise improves? What would a rehearsal still need to establish?

Assumption: every scheduled snapshot succeeds and is recoverable. The recovery duration includes restoring data, reconnecting dependencies, checking authorization, and verifying a customer task. This model does not represent continuous recovery or measure an actual system.
