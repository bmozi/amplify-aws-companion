John Briggs · Lessons 8–20

From a working app to cloud engineering

A practical path through changes, permissions, operations, and advanced Amplify capabilities.

Advanced courseFoundation lessonHands-on lab

You can already describe a page, a sign-in and a saved note. Now imagine another person depends on that app. You need to change it without losing their work, find the cause when it fails, and explain the resources and costs it leaves behind. These lessons build those skills one experiment at a time.

Start here

Complete the foundation exercises first. Work through identities, isolated practice, delivery and data changes. Later lessons add operations, reliability, AI, domains, integrations and a recovery capstone.

Some exercises run only on your computer; others propose billable AWS resources. A reading checkbox records neither a deployment nor a working customer path.

Before cloud work: use Lesson 18: cost controls to check the current account, plan, credits, full-run estimate and cleanup. Choose a spending limit and reserve for your own account. Keep organization-dependent exercises on paper unless you have a separately reviewed environment.

How to use each lesson

Read the example, make a prediction, perform only the steps for an environment you control, and compare the result with the evidence checklist. The source files and current helper flags live in the companion repository. Begin commands at the root of your own checked-out copy; review owner-bound account guards and targets before any cloud action.

Runnable local simulation; cloud design extension is optional

LESSON 14 · 60–90 minutes

Add an AI helper you can evaluate

Architecture exercise with optional service-specific implementation

LESSON 17 · 90–120 minutes

Prove you can operate, recover, and hand off the app

Capstone exercise; destructive tests only in disposable practice

Distinguish estimates, alerts and technical controls, then prove what remains after cleanup.

Local worksheet first; notification setup requires your own budget and recipient
