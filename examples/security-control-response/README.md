# A security finding is the start of a repair, not the repair receipt

Maya's shop stores private customer documents. A dashboard flags a possible exposure, a compliance row looks green, and a teammate proposes changing a policy immediately. The operator first needs to learn **which document, which account and Region, which principal, which time and which customer path** the signals describe. A broad “security fixed” claim cannot follow from a single green row.

Read [the illustrated control-response lesson](../../reader/BOOK-LOCATORS.md#book-48af2caaeefc6a0b). Record a first answer to each case before opening [assessor reasoning](ASSESSOR.md). All identities and records here are fictional; the cases create no AWS resource or paid detector.

| Case | Changed fact | Decide and name the evidence |
| --- | --- | --- |
| 1. An allow that still fails | An IAM policy simulator result for `s3:GetObject` says allow. The actual request is denied. | Which request principal, resource, policy types, condition context, service response and available audit records should be checked before changing anything? What did the simulation prove? |
| 2. An external-access finding | IAM Access Analyzer reports that a resource policy can share a document bucket outside the selected trust boundary. | Does the finding prove a customer actually downloaded a document? Which policy, analyzer scope, intended partner and positive/negative access tests distinguish authorized sharing from exposure? |
| 3. Strong sign-in, wrong reader | The operator uses MFA and a federated role; Bob can still read Alice's private note through the application. | Which identity boundary succeeded, and which application authorization rule failed? Where should the denial test run? |
| 4. The organization shortcut | A team proposes an SCP and Identity Center permission set in a single-account Free-plan learning sandbox to fix one operator permission. | Why must this stay design-only here? In a real multi-account design, what does each control do, and where does the ordinary IAM/resource permission still need review? |
| 5. A Trusted Advisor warning | A security check flags a named resource. Its result is old, and the proposed fix would delete the current production path. | Check account, resource identity, refresh availability under the support plan, owner and safe change plan. What would prove the warning is current, and what evidence would allow a bounded correction? |
| 6. A green conformance pack | Nine recorded resources comply with a Config conformance pack; one production export is outside the recorder's scope. | What can the green evaluations say? What inventory and recorder/evaluation evidence is missing? Would adding a rule by itself protect the unrecorded export? |
| 7. The next copy | A private uploaded document is copied into a public media area for a brochure. | Reclassify the copy from contents, owner and intended audience. Which allowed and denied reads, retention/backup paths and removal checks are needed? Can a tag enforce them alone? |
| 8. Encrypted but unavailable | A restored database is encrypted, but the recovery role cannot use its KMS key. | Separate ciphertext availability, key permission, key availability and useful application restore. Which exact read/decrypt and booking checks establish recovery? |
| 9. A certificate record | ACM shows a certificate, but the customer hostname presents a different or expired certificate. | Which endpoint/TLS observation matters? Explain why disabling hostname verification is not a fix and why at-rest encryption does not answer this transit question. |
| 10. A rotated secret | Secrets Manager holds a new supplier credential; one running worker still sends the old value. | What provider acceptance, worker refresh, old-value rejection and safe rollback evidence is needed? Why does a new stored version alone not finish rotation? |
| 11. Three findings | Inspector names a vulnerability in old image A, GuardDuty reports unusual activity for role B, and Security Hub shows a control finding for bucket C. | Which are vulnerability, activity and posture questions? Join by exact account/Region/resource/time; identify the deployed image and coverage before declaring one incident or a complete repair. |
| 12. The missing object event | The client saved a sanitized S3 `GetObject` denial with its request time and identifier. The team searches CloudTrail Event History, finds no object event, and says the request never happened. The existing trail did not select S3 object data events for this bucket. | What does the client response establish? Why can't Event History or this trail prove absence of the request? What would you inspect before planning future logging, and which costs, access, retention and test limits must you decide? |

Work through the [classification decisions](../data-classification/README.md), then run the [TLS boundary lab](../tls-boundaries/README.md), [credential-rotation lab](../credential-rotation/README.md), [security audit join](../security-audit-evidence/README.md), and [protective-control matrix](../protective-control-review/README.md) using the commands in their own READMEs. The matrix intentionally exits nonzero when review items remain. For the IAM and organization cases, use the [identity foundations](../identity-foundations/README.md) and [governance review](../governance-review/README.md) as **design** exercises. Keep the initial conclusion, local observation, Codex critique and corrected conclusion separate in a learning record. Ask Codex for the first missing scope or denial receipt, not for a policy that “makes it green.”

This packet does not simulate effective AWS IAM evaluation, Config, Trusted Advisor, Access Analyzer, Security Hub, GuardDuty, Inspector, KMS, ACM or Secrets Manager. Local TLS and rotation fixtures test only their named boundaries. Before any authorized live test, verify account-plan impact, scoped non-root identity, Region/resource support, a complete estimate, a stop rule, cleanup and delayed billing. Choose whole-run spending and reserve limits for the account you will use. Do not create an Organization or enable a paid service to answer these design cases.
