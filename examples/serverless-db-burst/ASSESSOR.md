# Assessor: six requests, two database seats

Keep this apart from the learner's first attempt. These are explanations of the local model and design questions, not a calibrated AWS exam key.

1. With three slots, three of six simultaneous local handlers save and three receive `database_busy`. The lab holds successful slot claims until every attempt has happened, so scheduling cannot turn a later release into a fourth success.
2. Three consumers and one local slot still complete six unique numbered jobs because workers wait for the semaphore. At most one holds it at a time. The fixture has no process restart, service time, rate limit, job failure or persistence; it cannot establish completion time or SQS behavior.
3. A function concurrency cap limits in-flight function work. It does not itself decide the customer's response or durably retain a synchronous request that was not invoked. The architecture must specify an API rejection/retake contract or an explicitly durable accepted-work path with a receipt, status lookup, duplicate-safe worker and deadline. A retry without an idempotency rule can repeat a business effect.
4. A source-level SQS maximum concurrency constrains that mapping. Function reserved concurrency constrains all invocations of the function, including other mappings and direct/API triggers. The configuration must be checked as a whole against database connections **and query capacity**, function runtime, batches, visibility timeout, retries and dead-letter or failure destinations. A connection proxy may reduce connection churn or reuse safe idle connections; it cannot make a slow query faster by declaration. AWS's current [SQS scaling documentation](https://docs.aws.amazon.com/lambda/latest/dg/services-sqs-scaling.html) notes that maximum concurrency and provisioned event-source mode cannot be configured together on the same mapping.
5. Provisioned concurrency prepares execution environments and can reduce initialization delay; it does not raise the database's two-slot model limit. It adds a separate charge. A meaningful proposal needs measurements of initialization, invocation concurrency, connection wait, SQL execution, error/throttle paths and customer latency before choosing controls. Review the [AWS concurrency guidance](https://docs.aws.amazon.com/lambda/latest/dg/configuration-concurrency.html) for the selected function mode.

If a learner says “the queue fixed the database,” ask which observation proves the database can process six *at once*. The local result proves six jobs eventually ran through a bounded, always-running, in-memory fixture. If a learner says “provisioned concurrency gives six connections,” ask for the database evidence. Neither answer follows from the run.
