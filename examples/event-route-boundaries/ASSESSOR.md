# Assessor reasoning: the cross-account and cross-Region event route

These are authored explanations for fictional design facts. They do not establish a working AWS route or a learner result.

1. `direct-reviewed-route` names the source role, supported destination claim, receiver bus admission, account-scoped receiver rule, target permission, local DLQs, same-bus archive replay, duplicate-effect review and fictional cost boundary. `ready_for_design_review` is the strongest valid result. The checker trusts every Boolean and string; it cannot inspect the actual policies or ask whether the operator received an alert.
2. `bus-policy-only` holds on `sender_role_not_reviewed`. The destination bus's permission is only one side of the route. Check the source rule target's EventBridge role and its `events:PutEvents` scope. If forwarding fails, inspect the source target's failure evidence and source-Region DLQ; a receiver-side search alone may find nothing.
3. `broad-receiver-rule` holds on `receiver_rule_scope_not_reviewed`. A `shop.deploy` event from the admitted training account is the near-match. An intended operations page should select both the booking account and `shop.deploy`, subject to current event-pattern behavior. A receiving bus that accepts several senders needs particular care with rules that omit `account`.
4. `third-hop-and-wrong-replay` holds on `unsupported_third_bus_hop` and `archive_replay_wrong_bus`. EventBridge does not forward an event that arrived by a bus-to-bus route through another bus target as proposed. An archive replays to its own source bus. Direct source-to-each-destination rules, or a separately authorized application that publishes a new event after a business decision, are different designs that require their own roles, costs and duplicate checks.
5. `lost-failure-and-duplicate-effect` holds on missing receiving-target permission, both failure destinations and replay-effect deduplication. The source forwarding DLQ belongs in the source rule's Region; the receiving target DLQ belongs in the destination rule's Region. Each standard SQS queue needs an effective write policy and an owner. Neither one proves that the human saw an alert. Replaying an event with operation ID `deploy-46` must reconcile the already attempted deployment before triggering a second effect.
6. `reserve-is-not-routing-permission` holds on the fictional credit reserve: $45 − $8 = $37, less than $40. That is independent of the run limit and gross headroom checks. No AWS credit or actual price was read. Add any route-specific transfer, archive retention, monitoring or downstream target cost that the selected design incurs.

The checker does not implement EventBridge pattern semantics, IAM evaluation, retry timing, SQS redrive, archive behavior or human receipt.
