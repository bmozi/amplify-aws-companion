# Changed-rule reasoning

The `temporary/` prefix includes `temporary/held/`; a second longer-retention rule does not automatically exempt those objects from the first rule. Redesign the classification and applicable rule scopes so the short rule cannot match held data; verify supported filters and inventory every affected version before a future change. `force_destroy = false` governs Terraform bucket removal, not S3 lifecycle deletion. Current and noncurrent age have different starting points, and adding another rule must remain in the one managed lifecycle configuration. A policy must meet the owner-approved 180-day requirement for each protected version. Immediate access removal belongs in authorization across current and version-specific paths; asynchronous storage expiration is not that gate. Validate syntax separately from owner approval, actual service behavior, recovery and costs. No apply is authorized by this worksheet.
