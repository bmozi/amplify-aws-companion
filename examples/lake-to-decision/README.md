# Carry one sale into a trustworthy chart

Read [the illustrated end-to-end lesson](../../reader/BOOK-LOCATORS.md#book-8a1fe562fcf3f6fc). Maya's shops send frequent sale records and a supplier sends a daily file. Finance needs a reproducible shop-day report; operations needs a fresher signal; a partner may receive only an approved aggregate. The eight cases are fictional design work. Write your own answer before the [assessor reasoning](ASSESSOR.md).

For each case, identify the source and business promise, the chosen path, a feasible alternative and why it loses, the enforcing identity/access boundary, a positive and negative test, complete cost categories, and the observation that would change your decision. A service name alone is not an architecture.

| Case | Changed condition | Decision to make |
| --- | --- | --- |
| 1. An impressive raw bucket | All files land in S3. A crawler registers a table. Its `shop_id` column turns `001` into `1`; a reader can fetch raw files directly. | Draw protected raw, validated and published areas. What prevents a bad row or unauthorized reader from becoming an approved chart? Which catalog and direct-object tests are distinct? |
| 2. A revoked grant | Yesterday's chart was exported to a partner's storage. Today finance revokes the table grant and assumes the earlier copy disappeared. | Who owns the export and its retention? How are query result locations, chart exports and direct S3 reads controlled? State the evidence needed for deletion or expiry. |
| 3. A one-time NAS move | A 6 TiB office archive is copied once to S3 before the old NAS is retired. The source changes during the copy. | Compare a supported direct client and DataSync. Include source inventory, final delta, verification, application read, transfer time bound, all cost terms and a safe retirement gate. |
| 4. A continuing supplier | A supplier must deliver a signed daily file over SFTP for the next year. An existing office application also needs an SMB share backed by stored files. | Explain why a transfer task, managed SFTP endpoint and file gateway answer different needs. Choose per workstream; state identity, outage/cache and continuing-cost checks. |
| 5. A flattering chart | A sale with two tags is joined to a tag table, while an untagged sale disappears. The dashboard total happens to equal the hand-written daily total. | Define the chart grain and expected row IDs; why is total equality insufficient? Which source-to-chart tests catch both errors? |
| 6. A partner's aggregate | The partner may see sales by week only if each group has at least five distinct customers; one group has ten purchases from one customer. | Choose an approved static export or constrained collaboration path. What must the visualization hide, and what does the group count establish or fail to establish? Keep cross-account work design-only. |
| 7. A five-minute promise | A five-minute batch schedule waits up to 300 seconds; transfer takes 24, processing 45 and publication 6. Another proposal collects every three minutes with the same 30 MB input assumption. | Compute the two modeled totals and remaining margin. Compare batch with retained streaming, including late records, lag, retries, replay and cost. |
| 8. Small files, big scan | The supplier changes from one daily file to 1,000 small files. A query still returns one chart number but scans every raw partition and includes an unaccepted file. | Select ingestion checks, partition/compaction or format changes, and a publication version. What source IDs, scan bytes, query permissions and correction evidence would prove improvement without changing the answer? |

Ask Codex to challenge your expected identities, source-to-output timing and bypass paths. Give it synthetic rows only. Check its service claims against current AWS documentation and have it list unknown prices instead of filling them with zero. Before any AWS run, verify a scoped non-root identity, selected Region and support, a complete estimate, a stop rule, cleanup and delayed billing. Choose whole-run spending and reserve limits for the account you will use. This packet creates no AWS resources; partner/cross-account implementation stays design-only.
