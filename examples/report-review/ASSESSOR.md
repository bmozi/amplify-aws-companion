# Assessor notes: integrated report review

Review the learner's reasoning, not whether they name a preferred service. These are expected elements, not evidence that a reader has demonstrated mastery.

1. At 60: 1,000 cents, A/42 counted, B/42 missing. At 131: 3,000 cents, both counted, neither missing against the stipulated manifest. A's replay adds nothing. Scope comes from a trusted producer context linked to the authorized sender; a body label alone is insufficient. The rejected 90,000-cent submission contributes nothing. Manifest agreement proves only agreement with that fixture.
2. Competing workers on one queue do not each receive every sale. Independent subscriptions or independently tracked consumers can meet that need, subject to the chosen transport's behavior. Each effect needs its own replay accounting. Analytical replay must not implicitly authorize another customer receipt. Merely saying “exactly once” does not explain the state boundary or crash recovery.
3. Compare an independently derived expected set and totals, including producer-scoped identity, types, currency, time semantics and rejected/conflicting records. Include a changed or missing-row negative case. Measure representative query results and resource use under stated conditions; a smaller file alone establishes neither a correct answer nor a cheaper complete workload.
4. Direct object access may bypass the intended query-level restriction. Inspect effective permissions and alternate access paths, rather than assuming the query policy controls all reads. Prefer fixing the required governed path. Any exported copy has its own retention and access boundary; revoking future reads cannot establish deletion of past copies.
5. Prevent an old job from replacing newer state, and enforce current authorization and the chosen source-version policy when returning results. Name the availability tradeoff if the source cannot be checked. Freshness checks do not establish relevance; evaluate results against the user's intended question and separately judged examples.
6. Ask which accounting period and report definition should carry the refund, how corrections are represented, and how readers distinguish provisional from revised reports. Preserve traceable adjustment evidence. Multiple business policies can be defensible; choosing one without the owner's requirement is the error.

Classify an answer as **needs revision** if it double-counts a retry, merges independent shop IDs, trusts the sender's shop label, assumes each shared-queue worker receives every message, equates file conversion with correctness, ignores the direct-file access path, or presents a local model as live cloud proof. Otherwise assess whether each proposed observation could actually distinguish success from failure. Have the learner revise the affected boundary and then trace the report end to end again.
