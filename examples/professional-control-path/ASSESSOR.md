# Professional control path: assessor reasoning

This is a rubric for fictional design answers, not a security certification, AWS policy evaluation, exploit test or learner result. Reward a precise actor/action/resource/path and a negative test. Reject the idea that one green control proves the entire request safe.

1. The record-owner authorization failed. HTTPS protects the connection and a WAF rule examines configured web properties; neither decides photo ownership. Repeat with a synthetic unrelated customer against every public and direct-object path; require denial without exposing the bytes. Review how the app binds object identity to the repair owner.
2. The security group's stateful allowance for an established connection does not override a stateless network ACL. Its return direction needs the appropriate destination ephemeral-port range and source/destination scope; inspect selected subnet associations, ordered rules and flow/path evidence. The supplied facts point to a return-path hypothesis, not proof of the live cause. Do not broaden all ports merely to make a test pass.
3. An endpoint policy limits requests through that endpoint and cannot replace the caller's identity/resource permissions. It cannot govern a route that does not traverse the endpoint. Check the selected request context, role, bucket policy, endpoint policy and actual DNS/route path. A successful endpoint test does not prove the alternate path denied.
4. Object read and decrypt are separate permissions and key availability is a separate dependency. Do not make the object public. Check exact principal, object version/path, key policy/grants and encryption context if used, then test allowed and adjacent denied access. TLS protects transport, not data ownership. A recoverable copy also needs usable target-key access.
5. Rotation is complete only when the stored value, supplier's accepted credential and active consumers agree, the intended calls work, and the old value is rejected under the stated transition policy. A cached worker and supplier acceptance of the old value contradict completion. Browser configuration is a public boundary. Review bounded cache lifetime and supplier/store outage behavior with synthetic values.
6. Patch Manager reports on supported managed-node patch state within its scope. It does not maintain application dependencies, establish that the image recipe includes the fix, or prove a safe booking/import result. Trace the running host, next launch image, application package and managed frontend separately. Test a replacement under the real work pattern and a compatible recovery route; record selected owner and deadline.
7. WAF Count records matching requests without blocking them; a bypassing origin is a separate ingress route. An IP-aggregated rate rule can group unrelated school-office users. Review normal and unwanted traffic, alternate-origin reachability, application-level fairness and downstream capacity before changing enforcement. Shield Advanced is not a prerequisite to this reasoning and would need its own business and cost decision.

Existing local labs establish only their fixtures. Actual effective IAM, KMS, network, WAF, secret rotation, patch coverage, cost and customer denial require selected AWS and application evidence. [IAM evaluation](https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_evaluation-logic.html), [security groups](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-security-groups.html), [network ACLs](https://docs.aws.amazon.com/vpc/latest/userguide/vpc-network-acls.html) and [endpoint policies](https://docs.aws.amazon.com/vpc/latest/privatelink/vpc-endpoints-access.html) are primary references, not proof of this fictional configuration.
