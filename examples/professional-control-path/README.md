# Professional control path: one repair photo, many gates

This fictional design assessment follows [Unit 31](../../reader/BOOK-LOCATORS.md#book-6ecc32e57e7bf91a), [E03](../../curriculum/EXERCISES.md#e03) and the book's existing [control-boundary figure](../../book/figures/protective-controls-at-scale.svg). It creates no AWS resources and uses no real customer data. Answer before opening the [assessor reasoning](ASSESSOR.md).

Maya's technician uses the public repair portal to open one approved photo. A private application worker reads the corresponding S3 object, decrypts it under a customer-managed key, and may call a supplier with a server-side credential. A separate EC2-based import job processes old repairs. For each changed case, draw the actual request or maintenance path and record: actor/principal; expected business action; DNS/route and return path; web, subnet and workload filters; IAM/resource/key decision; TLS and stored-copy protection; application ownership decision; bypass path; positive and negative test; evidence source and owner; cost and rollback/cleanup. State which proposed control can answer the question and which cannot.

1. **The signed-in intruder.** A legitimate customer changes the photo identifier in a request to another customer's approved photo. The request uses HTTPS and passes a WAF rule. The application returns the bytes. Name the failed business gate, the closest negative test and why stronger TLS or a wider network deny does not repair the ownership defect. Ask whether direct object URLs or a second API route bypass the intended check.
2. **The one-way path.** The private worker can send a request to a supplier on TCP 443. Its security group permits the outbound connection, but a custom subnet network ACL permits only the outbound destination port and denies the return destination's ephemeral port. The team sees a timeout. Explain what the stateful security group tracks, what the stateless subnet rules still need and which flow evidence would distinguish this from supplier rejection. Avoid recommending `0.0.0.0/0` on every port.
3. **The endpoint shortcut.** A worker reaches S3 through a selected VPC endpoint. The endpoint policy allows the selected object path, but the role lacks the needed S3 permission. Another worker reaches the same bucket by an allowed path outside that endpoint. Can the endpoint policy grant the first worker access or restrict the second path by itself? Name the identity/resource controls and route observations needed before making either claim.
4. **The readable ciphertext.** The worker may read the approved S3 object, but its decrypt request fails. A teammate proposes public object access because the bucket read succeeded. Distinguish object permission, key permission, key availability, TLS and application authorization. Include a negative check on an adjacent object and an independent recovery-key path.
5. **The supplier secret changes.** A Secrets Manager entry is rotated, but a long-running worker still uses a cached value and the supplier still accepts the old credential. Another teammate proposes copying the new value into browser configuration. Define the old-value rejection, target update, consumer refresh, expiry and outage checks. Decide which observations show rotation is actually complete.
6. **The patch report is green.** Systems Manager Patch Manager reports an EC2 import node compliant. Its application dependency has a known incompatible version and an old job image may still launch. A managed web frontend is also present. Assign host, image, dependency and web-application owners; define the tested replacement and rollback path. Explain why node patch compliance cannot prove the application or a new worker is safe.
7. **The burst and the bypass.** WAF is associated with the public web entry. Requests to an alternate origin reach the application directly; a legitimate school office shares one public IP and a rate rule counts that IP. Compare a WAF Count observation, an origin restriction, an application quota and a downstream capacity check. Name the false-positive and bypass evidence.
