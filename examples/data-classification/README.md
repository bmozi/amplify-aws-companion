# Decide what a derived report may reveal

Read [Give the information a handling rule](../../reader/BOOK-LOCATORS.md#book-f9082e15801f7edf). This is a fictional design exercise with no cloud calls, customer files or spending. Write your answer before reading the [assessor notes](ASSESSOR.md).

## Packet 1 — two inputs and one report

Maya combines an approved public maintenance guide with a customer-restricted photo. The draft PDF includes an address. A contractor says the report can be public because most of it came from the guide and the PDF is encrypted at rest.

Choose its current handling category, permitted audience and release condition. Explain why the file type, majority of public content and storage encryption do not decide the audience. Draw the original inputs, draft, export and proposed public copy.

## Packet 2 — a clean preview

An editor crops the address from the preview image. The downloadable PDF still contains the original photo as an attachment. Its metadata includes the customer's name. An AI summary omits the name but describes the only repair at a uniquely identifiable address.

Revise the decision using the actual contents of each artifact. Identify what must be inspected before a public version can be approved. Do not invent evidence that the report is anonymous.

## Packet 3 — approval belongs to a version

The owner approves sanitized version 4 for publication. Version 5 adds a new customer photo, but the publisher retains version 4's approval record. The original private photo still exists in an archive. A teammate proposes relabeling the entire folder public.

Explain which exact version has approval, which source restrictions remain and which automated check could stop a mismatched release. Then suppose version 4 is discovered to contain sensitive information after download: explain why changing its label is insufficient and what needs investigation.

## Transfer and assistance

Change the case to a staff-only schedule joined with customer invoice data. Does calling the output an “internal dashboard” make it available to every employee? Identify the missing audience/purpose rules and one allowed/denied test pair.

Ask Codex to challenge your first answer without adding facts to the packets. Keep the independent answer, AI suggestions and revised decision separately. Neither this authored exercise nor an AI answer establishes organizational compliance or learner mastery.
