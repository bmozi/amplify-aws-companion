# Assessor: certificate inventory versus served endpoint

Read this after writing the prediction and running the [local exercise](README.md). The expected result is not merely that the new certificate exists. The west client validates the practice CA and `localhost` name and observes a different certificate after the change. East still presents the old one, even though the fictional inventory marks both as replaced. A client asking for `wrong.example` must fail hostname validation.

For the near-expiry changed case, hold any claim that both entry paths are ready. Investigate the east listener's intended certificate association, deployment or propagation path and owning team. Recheck a fresh, validated connection to the exact east endpoint and the application response before closing the issue. The old certificate's expiry makes the timing urgent, but the local exercise does not model an expiry event or prove an AWS service outage.

For the wrong-hostname case, the new certificate's presence is insufficient. Check the requested hostname, certificate names, intended DNS/entry path and configuration. Preserve CA and hostname validation. Disabling it would hide the failure and remove the evidence that the client reached the intended named service.

A strong answer separates four records: certificate inventory, resource association/rollout, validated client observation for each path, and the customer's authorized result. The local program directly supplies only two listener observations and the wrong-name rejection. It cannot establish ACM renewal eligibility or status, imported-certificate reimport, AWS integrated-service deployment, real regional endpoints or customer authorization. Use [AWS managed-renewal eligibility](https://docs.aws.amazon.com/acm/latest/userguide/managed-renewal.html), [reimport behavior](https://docs.aws.amazon.com/acm/latest/userguide/import-reimport.html) and [renewal/deployment timing](https://docs.aws.amazon.com/acm/latest/userguide/troubleshooting-renewal.html) when evaluating an actual AWS design.
