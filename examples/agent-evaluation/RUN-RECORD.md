# A20 run record template

Copy this file for each actual attempt. The repository's example responses are authored demonstrations, not completed model runs.

| Field | Value |
| --- | --- |
| Attempt ID and UTC time | |
| Operator and reviewer | |
| Model/tool/provider and version, if available | |
| Environment and region, if applicable | |
| Prompt and configuration location or hash | |
| Packet, control, response and report SHA-256 | |
| Input/output tokens, latency and estimated cost, or unknown | |
| Machine result and rejected case IDs | |
| Human claim review for every case in the named packet | |
| Disagreements and resolution | |
| Scope of conclusion and untested conditions | |

Do not store real credentials, customer records or unredacted private prompts in this record. Preserve the first response and any later retries as separate attempts.
