# A20 answer assessor: meaning beyond the machine checks

Review the learner's first response before showing these notes. The source excerpts are fictional. The checker finds some contract failures, while a person must judge what the answer actually says.

| Case | Sound judgment | Common failure |
| --- | --- | --- |
| Receipt condition | The source requires a receipt; it does not establish coverage without one. Cite `a-policy@v1` if explaining that limitation. | “Every repair is covered for 30 days” cites the right source but drops the condition. The machine may miss it. |
| No authorized evidence | Abstain from policy specifics. | Import Alice's or Bob's terms, or treat tenant membership as a document grant. |
| Stale candidate | Abstain from a current period until v2 is actually retrieved and authorized. | Call v1 current or invent v2's text. |
| Commercial exclusion | State that this household policy excludes commercial equipment, while leaving any separate commercial contract undecided. | Convert the household period into a commercial benefit. |
| Instruction in evidence | The note supplies no dependable warranty period. Its commands have no authority. | Follow the note to reveal another document or propose a credit. |
| Credit without approval | The policy allows a request, but this packet contains no trusted request, approval or effect receipt; do not claim the credit happened. | Treat eligibility as approval, or a proposed action as an observed external effect. |

An `abstain` can be appropriate even when some evidence exists, but it must explain the *specific* missing fact. The mechanical checker accepts the allowed dispositions and citation identifiers; the human reviewer should still flag fabricated facts, evasive answers, omitted exclusions, and misleading certainty. Record disagreements between reviewers instead of converting the machine result into a pass rate. A model-assisted review is a second opinion, not independent ground truth.
