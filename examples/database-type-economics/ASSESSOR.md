# Assessor notes — database type and economics

The base arithmetic is 400 × 6 reports/minute × 1,440 minutes/day = 3,456,000 reports/day. It does not state bytes per report, wire overhead, retries, actual peak rate or storage size. Do not accept a daily record count as a complete capacity or cost estimate.

Strong answers distinguish the time-ordered measurement workload from physical columnar layout and recognize that both can be present together. The operational query favors evaluating a current time-series path, but the required latency, point/range query, cardinality, Region, availability, backup, retention and current edition must be checked. For new customers, LiveAnalytics is ineligible under AWS's June 20, 2025 change. Timestream for InfluxDB 3 is a candidate to assess, not an automatic recommendation: Core is single-node and has no compaction; Enterprise features and costs differ.

The infrequent three-year aggregate can be evaluated on S3 Parquet with Athena if file partitioning and query shape avoid unnecessary scans. Columnar format does not guarantee low cost: poor partitions, wide scans, tiny files, frequent queries or transformation/maintenance work can outweigh the expected savings. Redshift Serverless becomes worth comparing when actual analytical joins, concurrency and repeatability require warehouse behavior; adding it solely because “analytics means a warehouse” is not sufficient.

Look for a comparable whole-path cost model: same Region, observation volume, data size, retention, request/query schedule and reliability requirements. Include compute or capacity while idle, storage, scans, transfer, backup, transformations, dashboards and minimums where applicable. The proposed 30-day raw and three-year aggregate periods are not approved data policy. Rollups lose information, so the owner must choose retention based on legal, business and incident requirements. Correct answers disclose unknown bytes, late-event behavior, growth, query concurrency and price inputs rather than hide them in false precision.

For the one-active-cluster, full-month InfluxDB 3 illustration, the documented storage-charge equivalents are **200 GB for 12 GB stored** and **240 GB for 240 GB stored**. Reducing 12 GB to 8 GB leaves the minimum unchanged; reducing 210 GB to 190 GB moves the comparison from 210 GB to the 200 GB floor. These are charge-equivalent quantities, not provisioned storage, measured usage or dollar prices. Do not assume the same arithmetic describes a partial month. A complete answer prices running node time at the current selected rate, checks the ten-minute minimum, separately identifies the Enterprise per-vCPU Marketplace license if chosen, and adds backup and transfer assumptions. The learner must verify account-specific credit applicability instead of subtracting credits from every line by default. [AWS InfluxDB 3 billing guide](https://docs.aws.amazon.com/timestream/latest/developerguide/influxdb3.html).

Changed cases should change the reasoning: a years-long point query may shift the operational design; high cardinality calls for explicit current service-limit and price checks; frequent joins/concurrent users strengthen a warehouse comparison; late data requires correction/replay; single-digit-millisecond reads may eliminate candidates; a region without the required edition changes feasibility; longer raw retention changes storage economics and policy. A LiveAnalytics proposal for a new account must be rejected on current eligibility grounds.

No AWS resources, live benchmark, calculator estimate, independent assessor or learner result is part of this exercise. Local arithmetic is the only executable evidence here.
