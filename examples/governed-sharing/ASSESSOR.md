# Assessor notes: governed analytical sharing

1. Matching totals missed changed identity. Review exact values and types against the source contract before publication. A catalog entry and successful query establish neither preservation nor completeness.
2. Reader compatibility does not prove compatible writes. Athena's documented Iceberg path requires Glue catalog and Glue optimistic locking; the proposed different lock implementation is a material conflict to resolve before writes. Record supported versions and operations and test selected writers/failures in a separately authorized environment. Do not simulate a cloud transaction by renaming local files and call it equivalent.
3. The query route denied access, while the alternate route exposed data. Review effective IAM/S3 permissions and other applicable controls; test intended and forbidden paths after repair. Removing an arbitrary permission without preserving required service access is not a complete solution.
4. Data location permission concerns catalog-resource creation against the location. It does not independently authorize a table read. Trace the applicable table data permission, IAM and service integration rather than widening all permissions until a query succeeds.
5. One distinct customer fails the fictional minimum of five; five distinct customers satisfies that single condition. Row count is not distinct-person count. Correct identity/join semantics, other query rules, recipient knowledge and the broader sharing agreement remain separate questions. Five is a teaching input, not a universal safe threshold.
6. Revoking future table access cannot recall a delivered copy. Inventory outputs and recipients; define permitted use, deletion/retention ownership and evidence. Neither an absent source permission nor an empty new query proves deletion of the old export.

Accept more than one architecture when the answer explains its conditions. A small approved static report may need less machinery; evolving internal access may justify governed queries; a partner's constrained question may motivate a collaboration service. Require the learner to acknowledge copies, operational ownership and limitations in each choice.
