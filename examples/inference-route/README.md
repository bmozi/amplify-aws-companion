# Choose when a prediction must arrive

This is an offline architecture exercise for the [inference-path lesson](../../reader/BOOK-LOCATORS.md#book-48cc78d9103148e5). No model, endpoint, account call or credit is needed. Use the [four-route diagram](../../book/figures/four-inference-promises.svg). Write your answers before opening the [assessor reasoning](ASSESSOR.md).

Maya's repair company has an already trained photo-classification model. Its quality on new damaged parts is **unknown**. A prediction is advisory until a technician confirms it. For each case, choose a first serving candidate among SageMaker AI real-time, on-demand serverless, asynchronous inference and batch transform. State the caller's time promise, likely idle cost, one authorization boundary, the first measured test, and a reason to reject a tempting alternative. Check current model compatibility, payload/time limits, supported Region and pricing before any real deployment. [AWS inference options](https://docs.aws.amazon.com/sagemaker/latest/dg/deploy-model-options.html).

1. **Customer at the counter.** A technician needs a suggestion while the customer waits. The shop sees traffic throughout the day and has a strict response-time target. The model's actual latency under peak load has not been measured.
2. **One weekly inspection.** A supervisor can wait several seconds for a photo result. Requests are rare; a cold start is acceptable if measured within that limit. Someone proposes an always-on instance solely because the call is interactive.
3. **Long recording.** A repair video may take many minutes to process. The caller can accept a receipt and return later. The app currently has no job-status screen or way to authorize access to stored results.
4. **Monthly inventory.** At month end, operations has a complete set of part photos and wants predictions by the next morning. No one waits for individual HTTP responses.
5. **Changed promise.** Case 2 now requires a reliably short response during an unpredictable rush. The first on-demand trial has a long cold-start tail. Does the word “serverless” still settle the choice? Name a bounded comparison and the capacity cost you must price.
6. **Prediction versus action.** The model labels a part “safe,” but a technician sees a crack. Management proposes automatically denying the warranty claim from the prediction. State the separate quality, business-rule, authorization and human-review evidence that would be required. Which inference route alone supplies it?

For every answer, draw where protected images and predictions live and when they are deleted. Include the identity that can invoke the model and the one allowed to read its output. Keep input images fictional. This packet tests architectural reasoning only; it does not measure model accuracy, endpoint latency, current availability or cost. Use Codex to argue for a plausible alternative, then check the argument against the stated customer promise and official option limits.
